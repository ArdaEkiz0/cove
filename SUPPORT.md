# Support Cove

Thanks for using Cove. Here is the fastest way to get help without exposing private data.

## Before opening an issue

1. Read the [FAQ](docs/FAQ.md) and [Troubleshooting guide](docs/TROUBLESHOOTING.md).
2. Confirm you are on the latest release from [GitHub Releases](https://github.com/DevAnimecx/cove/releases).
3. Run `npm run typecheck && npm test` if you are building from source.
4. Check the browser console for errors and note your browser and extension versions.

## Where to ask

| Need | Best place |
| :--- | :--- |
| Install help, "how do I…" | [GitHub Discussions → Q&A](https://github.com/DevAnimecx/cove/discussions/categories/q-a) |
| Reproducible bug | [Bug report](https://github.com/DevAnimecx/cove/issues/new?template=bug_report.yml) |
| Feature idea | [Feature request](https://github.com/DevAnimecx/cove/issues/new?template=feature_request.yml) |
| Documentation problem | [Documentation issue](https://github.com/DevAnimecx/cove/issues/new?template=documentation.yml) |
| Accessibility problem | [Accessibility issue](https://github.com/DevAnimecx/cove/issues/new?template=accessibility.yml) |
| Security vulnerability | [Private security advisory](https://github.com/DevAnimecx/cove/security/advisories/new) — **never a public issue** |
| Press, partnership, or maintainer contact | Contact [@DevAnimecx](https://github.com/DevAnimecx) on GitHub |

## What to include

- Cove version (Settings → Data, or the release page).
- Browser and OS version.
- Steps to reproduce, expected behavior, and actual behavior.
- A screenshot or a short screen recording if the issue is visual.
- Console errors with secrets redacted.
- Whether the issue happens on a clean profile with no other extensions.

## Response window

Cove is a volunteer, local-first open-source project. Maintainers aim to triage new issues within **72 hours** and security reports within **48 hours**. Please be patient and kind; every contributor is donating their time.

## No private data

Cove never asks for your browsing history, notes, or backup files. Do not paste a full Cove backup into an issue — it may contain personal links and notes. Share a minimal reproduction instead.
