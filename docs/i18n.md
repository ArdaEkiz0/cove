# Internationalization

Cove ships five interface languages and applies the selected language before the app renders. The implementation is deliberately small: a typed dictionary in `src/lib/i18n.ts`, a persisted language code, and a pre-paint `lang` attribute.

## Supported languages

| Code | Language | Label |
| :--- | :--- | :--- |
| `en` | English | English |
| `hi` | Hindi | हिन्दी (Hindi) |
| `es` | Spanish | Español |
| `de` | German | Deutsch |
| `ja` | Japanese | 日本語 |

## How it works

- `LanguageCode` is a union type in `src/lib/types.ts`.
- `LANGUAGE_LABELS` maps each code to its display name.
- `DICT` holds the translations.
- `I18N_KEYS` is the canonical key list.
- `t(lang, key)` returns the translation, falls back to English for a missing key, and returns the key itself for an unknown key.
- `hasTranslation(lang, key)` reports whether a real translation exists.
- The selected language is saved in settings and mirrored to `cove_fast_boot` so `boot-theme.ts` can set `<html lang>` before paint.

The unit suite checks that every supported locale has every key, that values are non-empty, that placeholders such as `TODO` are absent, and that fallback behaviour is correct.

## Coverage

The dictionary covers the core shell: tagline, search placeholders, stage names, widget names, common actions, greetings, and settings entry points. It is not a complete translation of every settings description, documentation page, error message, or long-form product string.

This is intentional for `v0.1.1`: the goal is a usable localized shell, not a claim of full localization. New copy should be added to the dictionary when it is part of the core experience.

## Adding a language

1. Add the code to `LanguageCode` in `src/lib/types.ts`.
2. Add a label to `LANGUAGE_LABELS`.
3. Add a complete dictionary entry to `DICT`.
4. Add the code to the `LANGUAGES` array in `tests/i18n.test.mjs`.
5. Add the option to the language selector in Settings.
6. Run `npm test`, `npm run typecheck`, and `npm run build`.
7. Check the layout at compact and spacious scales; German and Hindi strings are often longer than English.
8. Add the language to this page and the README language list.

## Translation guidelines

- Translate meaning, not words. Keep the calm, specific voice.
- Preserve product names: Cove, Cove Discover, Cove News, Smart Engine, Focus Sanctuary.
- Keep placeholders and keyboard tokens unchanged.
- Avoid idioms that do not travel.
- Prefer short labels for controls; long explanations belong in body copy.
- Do not use machine translation without a fluent review.
- Keep punctuation consistent with the locale.

## Layout considerations

- Buttons and segmented controls must accommodate longer strings.
- Do not hard-code widths for labels.
- Test the settings rail and command palette with German and Hindi.
- Japanese does not use spaces between words; do not rely on word wrapping heuristics for truncation.
- The interface is LTR only. RTL support requires a separate layout pass and is not shipped.

## Dates, numbers, and time

Cove uses `Intl` APIs where practical for time and date formatting. Clock format is a user setting, not inferred only from locale. Currency conversion answers are informational and should not be treated as financial advice.

## Known limitations

- Documentation is English-only.
- Some settings descriptions and release notes remain English.
- No RTL language.
- No community translation workflow yet; contributions are accepted through pull requests.
- Translation coverage is not measured as a percentage in CI.
